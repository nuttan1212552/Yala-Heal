# วิธีเอา Yala Heal ขึ้นเว็บจริง + เชื่อมฐานข้อมูล

คู่มือนี้ทำครั้งเดียวจบ ไม่ต้องเขียนโค้ดเพิ่ม ทุกอย่างฟรี ใช้เวลาประมาณ 15–20 นาที

แบ่งเป็น 3 ช่วง:
1. สร้างฐานข้อมูล (Supabase)
2. เอาโค้ดขึ้น GitHub
3. เอาเว็บขึ้นออนไลน์ (Vercel) + ใส่คีย์ฐานข้อมูล

---

## ช่วงที่ 1 — สร้างฐานข้อมูลด้วย Supabase (ฟรี)

1. เข้า https://supabase.com แล้วกด **Start your project** → สมัคร/ล็อกอิน (ใช้ GitHub ล็อกอินได้เลย)
2. กด **New project**
   - ตั้งชื่อโปรเจกต์ เช่น `yala-heal`
   - ตั้ง **Database Password** (จดไว้ ไม่ต้องใช้บ่อย)
   - เลือก Region: **Southeast Asia (Singapore)** จะเร็วสุดสำหรับไทย
   - กด **Create new project** แล้วรอสักครู่ให้ระบบสร้างเสร็จ
3. เมนูซ้าย เลือก **SQL Editor** → **New query**
   - เปิดไฟล์ `web/supabase/schema.sql` ในโปรเจกต์นี้ คัดลอกทั้งหมด
   - วางในช่อง SQL แล้วกด **Run** (มุมขวาล่าง)
   - ถ้าขึ้น "Success" แปลว่าตารางถูกสร้างเรียบร้อย พร้อมข้อมูลตัวอย่าง
4. เอา **คีย์เชื่อมต่อ** — เมนูซ้ายล่าง **Project Settings** (รูปเฟือง) → **API**
   - คัดลอก **Project URL** (หน้าตาแบบ `https://abcdxxxx.supabase.co`)
   - คัดลอก **anon public** key (ข้อความยาว ๆ ขึ้นต้น `eyJ...`)
   - เก็บ 2 ค่านี้ไว้ จะใช้ในช่วงที่ 3

> หมายเหตุ: คีย์ `anon public` ปลอดภัยที่จะฝังในเว็บ (ออกแบบมาให้เปิดเผยได้) — **ห้ามใช้** คีย์ `service_role` ในเว็บเด็ดขาด

---

## ช่วงที่ 2 — เอาโค้ดขึ้น GitHub

ถ้ายังไม่มีบัญชี GitHub สมัครฟรีที่ https://github.com ก่อน

1. สร้าง repository ใหม่ (New repository) ตั้งชื่อเช่น `yala-heal` ตั้งเป็น Public หรือ Private ก็ได้
2. อัปโหลดโค้ดในโฟลเดอร์ `web/` ขึ้นไป (ถ้าใช้คำสั่ง git):
   ```bash
   cd web
   git init
   git add .
   git commit -m "Yala Heal web app"
   git branch -M main
   git remote add origin https://github.com/<ชื่อคุณ>/yala-heal.git
   git push -u origin main
   ```
   > หรือถ้าไม่ถนัด command line ใช้ GitHub Desktop ลากโฟลเดอร์ `web` เข้าไปก็ได้

---

## ช่วงที่ 3 — เอาเว็บขึ้นออนไลน์ด้วย Vercel (ฟรี) + ใส่คีย์

1. เข้า https://vercel.com → **Sign up** ด้วยบัญชี GitHub
2. กด **Add New… → Project** → เลือก repo `yala-heal` ที่เพิ่ง push ขึ้นไป
3. Vercel จะตรวจเจอว่าเป็น Vite อัตโนมัติ (Build = `npm run build`, Output = `dist`) — ปล่อยตามค่าเริ่มต้น
4. **สำคัญ:** ก่อนกด Deploy เปิดหัวข้อ **Environment Variables** แล้วใส่ 2 ค่าจากช่วงที่ 1:

   | Name | Value |
   |------|-------|
   | `VITE_SUPABASE_URL` | Project URL ที่คัดลอกมา |
   | `VITE_SUPABASE_ANON_KEY` | anon public key ที่คัดลอกมา |

5. กด **Deploy** แล้วรอสักครู่ → จะได้ลิงก์เว็บจริง เช่น `https://yala-heal.vercel.app`

เสร็จแล้ว! ลองกดลงประกาศในศูนย์แบ่งปัน หรือแจ้งเหตุ SOS แล้วเปิดในอีกเครื่อง/มือถือ จะเห็นข้อมูลเดียวกัน เพราะเก็บในฐานข้อมูลจริงแล้ว

---

## จะเช็คว่าเชื่อมฐานข้อมูลสำเร็จไหม?

- เข้าเว็บที่ deploy แล้ว → ไปหน้า **ศูนย์แบ่งปัน** → กด **ลงประกาศใหม่** → เพิ่มรายการ
- กลับไปที่ Supabase → **Table Editor** → ตาราง `donations` → ถ้าเห็นรายการที่เพิ่ง เพิ่ม แปลว่าเชื่อมสำเร็จ 🎉

## ถ้าอยากรันในเครื่องตัวเองก่อน (ไม่บังคับ)

```bash
cd web
cp .env.example .env.local      # แล้วแก้ค่าในไฟล์ .env.local ใส่ URL + key จริง
npm install
npm run dev                     # เปิด http://localhost:5173
```

ถ้าไม่ใส่ค่าใน `.env.local` เว็บจะยังเล่นได้ แต่ใช้ข้อมูลจำลอง (ไม่บันทึกจริง)

## หมายเหตุด้านความปลอดภัย (สำหรับใช้งานจริง)

ตอนนี้ตั้งค่าให้ทุกคนอ่าน/เพิ่มข้อมูลได้ (เหมาะกับ **เดโมงานแข่ง**) ถ้าจะใช้จริงกับข้อมูลประชาชน ควรเพิ่ม:
- ระบบล็อกอิน/ยืนยันตัวตน (Supabase Auth หรือเชื่อม ThaID จริง)
- ปรับ RLS policy ให้จำกัดสิทธิ์ตามบทบาท (ประชาชน/เจ้าหน้าที่)
- ย้ายการเขียนข้อมูลอ่อนไหว (เยียวยา/สุขภาพจิต) ไปผ่าน backend ที่ตรวจสอบสิทธิ์
